Something gone quiet?

Start here
The speaker doesn’t appear

Join the same local network as the jukebox. Guest Wi-Fi and client isolation can block discovery. Ask IT to allow multicast DNS (UDP 5353) between the phone and the device. Open Spotify on the same Wi-Fi for initial discovery.

Connected, but there’s no sound

Check the amplifier power, cable and volume. If Spotify is waiting, disconnect AirPlay. In Settings, check the master volume. Audio health confirms the output exists; only listening can verify the speakers.

Music drops out or stutters

Use Ethernet for the jukebox. Keep the phone’s Wi-Fi signal strong for AirPlay. Spotify needs working internet and a Premium account. Check network isolation and DNS before restarting a receiver.
